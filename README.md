# 📝 文本审核插件 (astrbot_plugin_text_moderation)

> 智能文本审核插件，支持关键词检测 + AI 语义分析，实现分级管控、自动学习、管理员权限、违规记录持久化、私信通知、WebUI 四标签页管理。
>
> 👤 **作者：** 吃糖吃没了 · 🤖 **AI 辅助开发**

## ✨ 功能特性

### 🔍 双重检测机制
- **关键词检测**：快速匹配已知的违禁词，毫秒级响应
- **AI 语义分析**：调用 AI 模型进行深度语境判断，识别隐晦表达

### 📊 分级管控
- **🔴 严重违规（BLOCK）**：色情、涉政、暴力、涉及未成年的性暗示等 → 撤回 + 计入惩罚次数 + 通知管理员
- **🟡 轻度违规（WARNING）**：轻度辱骂、低俗用语 → 仅警告 + 撤回，不计入惩罚次数
- **🟢 安全（SAFE）**：正常交流，不干预

### ⚖️ 自动惩罚
- 严重违规累计达到阈值后自动执行惩罚
- 支持 **禁言（mute）** 和 **踢出群（kick）**
- 可配置惩罚次数阈值和时间窗口
- 轻度违规不影响惩罚计数

### 🧠 AI 自动学习
- AI 审核发现违规时，自动提取违规关键词加入词库
- 词库持续积累，拦截速度越来越快
- 减少重复调用 AI 的次数，节省 API 费用

### 🎯 智能语境判断
- 支持白名单机制（如"萝莉"在二次元圈子是正常用语）
- AI 根据上下文判断是否违规（"喜欢萝莉"安全，"草萝莉"违规）
- 识别谐音、拆字、拼音等绕过手段
- 识别阴阳怪气式人身攻击，区分「对事」（正常吐槽）和「对人」（人身攻击）

### 🎭 阴阳怪气 / 人身攻击识别
- **对事不对人 = SAFE**：吐槽观点、作品、事物 → 正常讨论，不拦截
- **对人不对事 = WARNING**：贬低人格、智商、外貌、能力 → 轻度违规，警告+撤回
- AI 判断技巧：把主语换成"这个观点/这件事"，如果不通顺就是对人的攻击
- 例如："你怕不是个傻子吧"→对人→违规；"这观点有点蠢"→对事→正常

### 👮 管理员权限控制
- 可设置管理员QQ号列表
- `/清空违规记录`、`/移出黑名单` 等命令需要管理员权限
- 非管理员执行会提示无权限

### 💾 违规记录持久化
- 违规记录保存到本地文件，重启 AstrBot 不丢失
- 记录详情：用户ID、群号、违规内容、违规原因、等级、时间、来源
- 最多保留 500 条记录

### 📨 违规私信通知管理员
- 发现违规时自动私信通知所有管理员
- 通知内容包含：用户ID、群号、违规等级、违规内容、违规原因、时间
- 可在配置中开关

### 🌐 WebUI 三标签页管理界面
- **标签页1：违禁词管理** - 添加、删除、清空违禁词
- **标签页2：违规记录** - 表格展示违规详情，支持清空单用户或全部
- **标签页3：管理员设置** - 添加、删除管理员QQ号
- 所有数据保存在本地，不涉及网络传输

## 📦 安装

1. 将 `astrbot_plugin_text_moderation.zip` 上传到 AstrBot
2. 在 AstrBot WebUI → 插件管理中安装
3. 安装后重载插件

## ⚙️ 配置说明

在 AstrBot WebUI → 插件管理 → 文本审核插件 → 配置中修改：

### 基础设置
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `ai_provider` | AI 模型提供商 | 当前默认 |
| `allowed_groups` | 允许审核的群号（空=全部） | `[]` |
| `min_message_length` | 最小审核消息长度 | `2` |

### 审核开关
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `enable_auto_moderation` | 启用自动审核 | `true` |
| `enable_keyword_moderation` | 启用关键词审核 | `true` |
| `enable_ai_moderation` | 启用 AI 审核 | `true` |
| `enable_intercept_message` | 启用消息拦截 | `true` |
| `enable_recall_message` | 启用消息撤回 | `true` |
| `enable_auto_collect` | 启用 AI 自动收集违禁词 | `true` |

### 敏感词过滤
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `word_whitelist` | 白名单词（不算违规） | `["萝莉", "二次元"]` |
| `strict_mode` | 严格模式（全词匹配） | `false` |

### 量刑管控
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `enable_punishment` | 启用量刑管控 | `true` |
| `enable_warning_punishment` | 启用轻度违规警告 | `true` |
| `enable_block_punishment` | 启用严重违规惩罚 | `true` |
| `enable_blacklist` | 启用黑名单 | `true` |
| `punishment_time_window` | 违规计数时间窗口（分钟） | `60` |
| `block_punishment_count` | 严重违规惩罚阈值 | `2` |
| `block_punishment_action` | 惩罚动作（none/mute/kick） | `kick` |
| `block_punishment_duration` | 禁言时长（分钟） | `120` |

### 管理员与通知
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `admin_list` | 管理员QQ号列表 | `[]` |
| `enable_admin_notify` | 启用违规私信通知管理员 | `false` |

## 🚀 使用方法

### 自动审核
插件会自动审核群消息，无需手动操作。审核流程：

```
消息发送
  ↓
关键词检测（快速）
  ├─ 命中严重违禁词 → 撤回 + 警告 + 计入惩罚次数 + 记录详情 + 通知管理员
  ├─ 命中轻度违禁词 → 撤回 + 警告（不计入惩罚）+ 记录详情 + 通知管理员
  └─ 未命中 → AI 语义分析
                  ├─ BLOCK → 撤回 + 警告 + 计入惩罚次数 + 记录详情 + 通知管理员 + 自动收集关键词
                  ├─ WARNING → 撤回 + 警告（不计入惩罚）+ 记录详情 + 通知管理员 + 自动收集关键词
                  └─ SAFE → 放行

严重违规次数累计达标 → 禁言 or 踢出群
```

### 指令列表

| 命令 | 别名 | 权限 | 说明 |
|------|------|------|------|
| `/审核 <文本>` | `text_check`, `check_text` | 所有人 | 手动审核指定文本 |
| `/查看违规记录 [用户ID]` | `check_violations`, `violation_log` | 所有人 | 查看违规次数和时间 |
| `/清空违规记录 [用户ID]` | `clear_violations` | 🔒 管理员 | 清空指定用户的违规记录 |
| `/查看黑名单` | `show_blacklist`, `blacklist` | 所有人 | 查看黑名单列表 |
| `/移出黑名单 <用户ID>` | `remove_blacklist`, `unban` | 🔒 管理员 | 将用户移出黑名单 |
| `/查看敏感词 [类型]` | `show_words`, `word_list` | 所有人 | 查看敏感词列表（类型：blocked/warning） |
| `/重载敏感词` | `reload_words` | 所有人 | 重新加载敏感词配置文件 |

> 🔒 标记的命令需要管理员权限，需在配置或 WebUI 管理页面设置管理员QQ号

### WebUI 管理界面

1. 打开 AstrBot WebUI → 插件管理
2. 找到"文本审核插件"
3. 点击插件卡片进入管理页面

   - **管理员设置**：添加、删除管理员QQ号（自动保存到配置）

## 📋 违规分级示例

### 🔴 严重违规（BLOCK）
| 消息 | 原因 |
|------|------|
| 色情、涉政内容 | 直接违规 |
| "草萝莉" | 性行为+未成年 |
| "大调查小萝莉" | 谐音性暗示+未成年 |
| "强碱小萝莉" | 谐音"强奸"+未成年 |
| "弓虽女干" | 拆字绕过 |

### 🟡 轻度违规（WARNING）
| 消息 | 原因 |
|------|------|
| "你妈" | 轻度辱骂 |
| "傻子" | 轻度侮辱 |
| "大调查"（无萝莉） | 低俗脏话 |
| "你怕不是个傻子吧" | 人身攻击（对人） |
| "就你这智商还说话" | 人身攻击（对人） |
| "您可真厉害呢"（反讽） | 阴阳怪气式人身攻击 |
| "你脑子有问题" | 人身攻击（对人） |

### 🟢 安全（SAFE）
| 消息 | 原因 |
|------|------|
| "喜欢小萝莉" | 正常二次元语境 |
| "萝莉很可爱" | 正常二次元语境 |
| "香草"（单独） | 正常词汇 |
| "这电影拍得真烂" | 对事不对人，正常吐槽 |
| "这个观点有点蠢" | 对事不对人，批评观点 |
| "你说的不对，因为..." | 正常辩论和观点交锋 |

## 🛡️ 隐晦表达识别

AI 能识别以下绕过手段：

| 类型 | 示例 | 实际含义 |
|------|------|---------|
| 谐音替换 | "强碱" | "强奸" |
| 拆字 | "弓虽女干" | "强奸" |
| 拼音/英文 | "qiangjian" | "强奸" |
| 符号插入 | "强\*奸" | "强奸" |
| 隐晦表达 | "大调查" | "大屌查/插" |
| 语境暗示 | "香草萝莉" | "想操萝莉" |

## 🔧 工作原理

### 三层防线

1. **关键词库**（第1层）：快速拦截已知违禁词，不调用 AI
2. **AI 语义分析**（第2层）：识别新的、隐晦的违规表达
3. **用户手动**（第3层）：在 WebUI 手动添加漏网的词

### 自动学习流程

```
第1次发现"香草萝莉"
  → 关键词库无"香草" → 调用AI
  → AI判定违规，提取"香草"
  → "香草"自动加入词库
  → 记录违规详情 + 通知管理员

第2次发现"香草萝莉"
  → 关键词库有"香草" → 直接拦截
  → 不需要调用AI，秒拦
  → 记录违规详情 + 通知管理员
```

### 违规记录存储

```
plugin_data/astrbot_plugin_text_moderation/
├── sensitive_words.json      # 违禁词库（blocked + warning）
└── violation_records.json    # 违规记录（详情 + 用户计数）
```

违规记录文件格式：
```json
{
  "records": {
    "123456": {"warnings": [时间戳], "blocks": [时间戳]}
  },
  "details": [
    {
      "user_id": "123456",
      "group_id": "789",
      "content": "违规内容",
      "reason": "违规原因",
      "level": "block",
      "timestamp": 1690000000,
      "source": "keyword"
    }
  ]
}
```

## ⚠️ 注意事项

1. **机器人权限**：执行禁言/踢人/撤回需要机器人在群内有管理员权限
2. **AI 模型**：建议使用 GPT-4、Claude 等能力较强的模型，对隐晦表达识别更准确
3. **本地部署模型**：千问 14b 等中等规模模型对谐音识别能力有限，可通过手动添加词库补充
4. **平台支持**：禁言/踢人/撤回/私信功能在 aiocqhttp（NapCat）平台下测试通过
5. **误判处理**：如发现误判，可在 WebUI 管理页面手动删除对应词
6. **管理员设置**：务必在配置或 WebUI 中设置自己的QQ号为管理员，否则无法执行管理命令
7. **私信通知**：需要机器人能向管理员发送私信（NapCat 需管理员添加机器人为好友）
