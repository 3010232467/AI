Features

强大的功能特性

多重审核机制，智能识别各种违规内容，让群聊管理更轻松

🔍

双重检测机制

关键词检测快速匹配已知违禁词（毫秒级响应），AI 语义分析深度语境判断，识别谐音、拆字、拼音等隐晦表达。

📊

分级管控

严重违规（BLOCK）撤回+禁言/踢人，轻度违规（WARNING）仅警告不影响计数，安全消息（SAFE）不干预。

🧠

AI 自动学习

AI 审核发现违规时自动提取关键词加入词库，词库持续积累，拦截速度越来越快，节省 API 费用。

🎭

阴阳怪气识别

智能区分「对事」（正常吐槽）和「对人」（人身攻击），对事不对人放过，对人不对事警告撤回。

💾

违规记录

违规记录保存到本地文件，重启不丢失。记录包含用户ID、群号、内容、原因、等级、时间、来源。

🌐

WebUI 管理

四标签页管理界面：违禁词管理、违规记录、管理员设置、API 消耗统计，操作简单直观。

👮

管理员权限

可设置管理员列表，清空违规记录、移出黑名单等命令需要管理员权限，确保操作安全。

📈

Token 计量

自动统计 AI 调用量和 Token 消耗，支持多模型价格换算，每日/每月历史数据查看。

📨

私信通知

发现违规时自动私信通知所有管理员，包含详细违规信息，及时掌握群聊动态。

🚧

Workflow

审核工作流程

每一条消息都经过严格的多重检测，确保群聊环境的安全与和谐

1

消息接收

插件监听群聊消息，接收每一条新消息并进行预处理。

2

关键词检测

快速匹配词库中的违禁词，毫秒级响应，已知违规词直接拦截。

3

AI 语义分析

通过 AI 模型进行深度语境判断，识别隐晦表达、阴阳怪气等绕过手段。

4

分级判定

根据违规程度判定为 BLOCK（严重）、WARNING（轻度）或 SAFE（安全）。

5

执行处理

撤回消息、警告用户、累计违规次数、触发自动惩罚，并通知管理员。
